LocalTranscriber: графический интерфейс для Windows

Что внутри:
- gui_transcriber.py — локальное приложение с окном выбора видео, моделью Small и словарём терминов
- setup_gui.bat — однократная установка python-docx (экспорт Word)
- start_transcriber.bat — запуск приложения двойным щелчком

Установка:
1) Распакуйте все файлы из архива В ПАПКУ существующего проекта:
   C:\Users\lenovo\LocalTranscriber
   Рядом уже должны находиться папка .venv и файл transcribe.py.
2) Запустите двойным щелчком setup_gui.bat. Этот шаг нужен один раз.
3) Запустите двойным щелчком start_transcriber.bat.
4) Нажмите «Выбрать файл…», укажите MKV/MP4/MP3 и нажмите «Распознать».
5) Результаты появятся в папке output: TXT, SRT, DOCX.

Внимание:
- Приложение не меняет transcribe.py, benchmark_models.py и их настройки.
- Для базовой транскрибации сохраняется faster-whisper из существующего .venv.
- Локальное распознавание не отправляет запись в облако. При первом выборе
  модели может потребоваться скачать её веса через интернет.
- Индикатор показывает ход работы, не точный процент выполнения.
- Прерывание программы во время распознавания может не сохранить текущий результат.
- Используйте документы только после проверки важных цитат по оригиналу.
